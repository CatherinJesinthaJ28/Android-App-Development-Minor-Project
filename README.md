# Android App Development Minor Project

A Flutter-based Android application developed as a minor project, featuring an interactive calculator and a user registration form. The application demonstrates Flutter UI development, navigation, form validation, state management, and basic application logic using Dart.

## Project Overview

This project combines two independent functionalities in a single application:

- A Calculator for performing basic arithmetic operations.
- A Registration Form for collecting and validating user information.

The application provides a simple, user-friendly interface with a purple-themed Material Design layout.

## Features

### 1. Calculator

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal number support
- Clear calculator functionality
- Division-by-zero handling
- Dynamic result display

### 2. Registration Form

- Full Name input
- Email input with basic validation
- Phone Number input
- Gender selection dropdown
- Password input
- Password visibility toggle
- Required field validation
- Minimum password length validation (6 characters)
- Registration success notification

### 3. User Interface

- Welcome screen with application navigation
- Separate Calculator and Registration screens
- Material 3 design
- Purple color theme
- Gradient background for registration screen
- Scrollable layouts
- Developer and college information displayed in the application

## Technologies Used

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Android Studio or an Android device/emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/CatherinJesinthaJ28/Android-App-Development-Minor-Project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Android-App-Development-Minor-Project
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
